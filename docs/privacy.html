Privacy policy

commit-live light

Last updated October 15, 2026 (permissions and Marketplace plan events added). This covers the commit-live light GitHub App (App ID 5337969) and its webhook server at commit-live-app-production.up.railway.app, run by Joshua Almeida. The commit-live GitHub Action runs in your own GitHub Actions and sends nothing to us.

What the App reads

Only repositories you install it on, using the permissions you approve:

  • webhook events GitHub sends for those repositories: push, pull request, workflow run and check run;
  • the workflow runs on a commit (names, events, status and conclusion), to decide whether the commit is lit or dark;
  • its own commit-live check runs;
  • when someone clicks Go live: that person's permission level on the repository and the repository's Pages settings.

It does not read your source code. Go-live fetches only the gh-pages branch.

The permissions it asks for are exactly: Checks read & write, Contents read & write, Actions read, Pull requests read (only so GitHub sends pull request events), Pages read and Metadata read.

If you get the App through GitHub Marketplace, GitHub also sends a plan event (purchased, changed or cancelled) with your account name, account ID and plan. The App's one plan is free; that event is written to the server log once and nothing else.

What the App writes

  • commit-live check runs on your commits (lit or dark, with a short summary);
  • on Go live: a commit to your gh-pages branch that copies c/<sha>/ to the root, plus a live.json file in that branch with the commit sha, a link to the check, the time, and the GitHub username of the person who clicked. That file is in your repository and is public if the repository is public.

What we store

  • No database, no files. The server keeps only, in memory: the IDs of recent webhook deliveries (to drop duplicates), and short-lived installation tokens from GitHub (about one hour). Both are lost on every restart.
  • Server logs. Each event writes one log line with the repository name, short commit sha, event type, delivery ID and result (lit, dark, waiting, live or refused). Refusals can include the GitHub username of the person who clicked, and Marketplace plan events log the account name, ID and plan. Logs are kept by our host, Railway, under its retention policy for the plan in use. We don't export, sell or share them, and we don't use them for anything but running and debugging the App.
  • No cookies, analytics, tracking or advertising. We never ask for personal data beyond what GitHub includes in webhooks.

Who else sees data

GitHub, which sends the webhooks and hosts your repository and Pages site, and Railway, which hosts the server. No one else.

Removing data

Uninstall the App from your account or organization settings, and it gets no more events or access. Check runs and gh-pages commits it made are in your repository, and you can delete them there. To ask about log lines for your repositories, email us.
