Common answers

  • The check says "waiting": the light is set when every push and pull request workflow run on the commit has finished.
  • "No workflow run yet, so no light": the commit has no push or pull request workflow run. No data is not a light.
  • Go live was refused: only a lit commit with a preview at c/<sha>/ on gh-pages can go live, and only someone with write access can do it. The check's summary says which of these failed.
