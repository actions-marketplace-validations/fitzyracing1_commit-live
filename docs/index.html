commit-live light

Live on a commit. Every commit gets a lit or dark light from its own workflow runs. A lit commit can go live with one click: the GitHub Pages root then serves that commit's preview build. Nothing is merged.

  • GitHub App (commit-live light): writes its own commit-live check on each push and pull request. The check is lit only when every push or pull request workflow run on the commit is lit, and only a lit check shows Go live.
  • GitHub Action (uses: fitzyracing1/commit-live@v1): runs your tests, posts the light, and deploys a preview at /c/<sha>/ on your gh-pages branch.
